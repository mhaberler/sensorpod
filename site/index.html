SensorPod

Firmware … — flash from the browser over USB (Chrome / Edge, desktop).

Your browser lacks Web Serial — use desktop Chrome or Edge. Page must be served over HTTPS.

After flashing, WiFi can be set up right here (Improv). Otherwise the device runs a WPA2 AP whose SSID and password are both <hostname>.local.

Erasing wipes stored WiFi credentials and settings; skip it to keep them on update.
